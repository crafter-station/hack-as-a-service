# Hack as a Service

An operating system for an Organizer to create a Hackathon, receive Projects, and run judging. It is not a public directory of hackathons.

## Language

**Organizer**:
A person who creates and operates Hackathons.
_Avoid_: host, admin, platform

**Hackathon**:
A time-bounded contest an Organizer creates to collect Projects and run judging.
_Avoid_: event, jam, listing, contest

**Project**:
The submitted artifact for a Hackathon: a name, a link, an image, and participant emails. Not a user account.
_Avoid_: submission, entry, team

**Participant**:
A person listed by email on a Project. Has no login.
_Avoid_: user, member, hacker

**Judge**:
A named person invited to score Projects. Opens judging with an Access Code, not Clerk.
_Avoid_: reviewer, evaluator

**Access Code**:
The secret a Judge uses to open judging for one Hackathon.
_Avoid_: password, token, invite

**Rubric**:
The Criteria an Organizer defines for a Hackathon.
_Avoid_: scorecard, metrics

**Criterion**:
One named dimension on a Rubric, with a weight percent.
_Avoid_: metric, category

**Rating**:
A Judge's integer from 1 to 5 for one Criterion on one Project.

**Score**:
The weighted result of a Judge's Ratings on a Project, on a 0–100 scale.
_Avoid_: mark, grade
