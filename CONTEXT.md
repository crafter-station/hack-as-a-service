# Hack as a Service

An operating system for an Organizer to create a Hackathon, receive Projects, and run judging. It is not a public directory of hackathons.

## Language

**Organizer**:
A person who creates and operates Hackathons.
_Avoid_: host, admin, platform

**Hackathon**:
A time-bounded contest an Organizer creates to collect Projects and run judging.
_Avoid_: event, jam, listing, contest
